# 每日英语新闻跟读 · The Daily Shadowing Gazette

面向零基础成人学习者的英语新闻跟读应用：每天推送真实新闻（The Guardian），逐句跟读、神经网络真人发音（美音/英音可选）、逐句中文翻译、生词/特殊用法/语法自动标注、生词本复习。

## 在线访问

https://aflyingfly.github.io/daily-shadowing-gazette/

## 本地开发

```bash
npm install
npm run dev
```

> 神经网络语音依赖开发服务器的 `/edge-tts` 中转，仅本地预览可用；GitHub Pages 静态版会自动使用系统语音。

## 技术栈

React + TypeScript + Vite + Tailwind CSS + shadcn/ui
